# SVG Illustration Composer 🎨

Интерактивный веб-сервис для сборки иллюстрационных композиций из векторных SVG-компонентов по тестовому заданию.

---

## 🌟 Возможности и сценарии использования

### 1. Автоматическая сборка по метафоре (Сценарий 1)
- Пользователь вводит метафору, тему или заголовок (например, *«удалённая работа»*, *«технологии и аналитика»*, *«обучение»*).
- Алгоритм семантического подбора оценивает релевантность компонентов из библиотеки.
- Сервис автоматически выстраивает сбалансированную изометрическую композицию с учётом планов (главные объекты на переднем плане, фоновые — на заднем, с естественным масштабированием и углами).

### 2. Ручная компоновка и выбор компонентов (Сценарий 2)
- **Библиотека компонентов:** вкладки «Главные» (цветные акцентные) и «Фоновые» (монохромные элементы окружения).
- **Drag & Drop:** перетаскивание компонентов прямо из боковой панели на интерактивный холст в нужные координаты.
- **Быстрое добавление:** двойной клик по компоненту в библиотеке.
- **Выбор списком:** в модальном окне «Авто» можно отметить галочками нужные компоненты, и сервис сам скомпонует их в готовую сцену.

### 3. Инструменты манипуляции и свойства объектов
- **Трансформация на холсте:** интерактивное перетаскивание курсором (Pointer Events), поворот с шагом 15°, масштабирование (10–300%), точные числовые координаты X/Y и размеры W/H.
- **Управление слоями:** перемещение объектов выше/ниже по оси Z (`Layer Up` / `Layer Down`, горячие клавиши `[` и `]`), дублирование (`Ctrl+D`), удаление (`Delete` / `Backspace`).
- **Смена роли (Главный ↔ Фоновый):** мгновенное переключение режима объекта с автоматическим изменением прозрачности (45%) и монохромной фильтрацией.
- **Холст и форматы:** переключение форматов в 1 клик — Горизонтальный (1200×630), Квадратный (800×800), Вертикальный (630×1200). Масштабирование (Zoom) и центрирование (Fit to View).

### 4. Динамические палитры (3 цветовые схемы)
Мгновенное перекрашивание композиции на холсте и всех миниатюр в библиотеке:
- 🟣 **Фиолетовая** (`#C4B0E0`, `#A78BC5`, `#D6C8EE`, `#524365`)
- 🟡 **Бежево-оранжевая** (`#F0DFA0`, `#E5C88A`, `#F5E8B0`, `#6A5636`)
- 🔵 **Сине-голубая** (`#A0C4E8`, `#7BA8D4`, `#C0D8F0`, `#385575`)

### 5. Размеры компонентов (L и S)
- **L (Large):** детализированные полноразмерные векторные иллюстрации.
- **S (Small):** облегчённые, компактные версии с адаптированной толщиной штриха и упрощённой графикой.

### 6. Векторный экспорт (SVG Export)
- Экспорт чистых векторных SVG-файлов без растеризации, рамок редактора или вспомогательной сетки.
- Файлы готовы к использованию в веб-дизайне, верстке или Figma.

## 🛠 Архитектура и стек технологий

Проект реализован без тяжеловесных сторонних фреймворков для обеспечения максимальной производительности, чистоты кода и полного контроля над SVG DOM.

- **Сборщик:** Vite (быстрая сборка, HMR, мгновенный старт).
- **Core:** Vanilla JavaScript (ES-модули, компонентная событийно-ориентированная архитектура).
- **Styling:** Vanilla CSS (CSS Custom Properties, Glassmorphism, микроанимации, тема Dark Premium, шрифт Inter).
- **Графика:** Чистый SVG (DOM-манипуляции, матричные трансформации координат `getScreenCTM().inverse()`, сохранение векторных путей).

### Структура модулей:
```
├── index.html              # Разметка приложения и модальных окон
├── public/
│   └── svg/
│       ├── L/              # 22 детальных SVG-компонента
│       └── S/              # 22 упрощённых SVG-компонента
├── src/
│   ├── css/
│   │   └── index.css       # Дизайн-система, темы, сетка, компоненты
│   └── js/
│       ├── app.js          # Точка входа, координатор модулей и горячих клавиш
│       ├── library.js      # Метаданные компонентов, загрузка, поиск и фильтрация
│       ├── canvas.js       # Ядро холста: выделение, перемещение, трансформация, слои
│       ├── colorizer.js    # Менеджер 3 палитр и алгоритм динамической перекраски
│       ├── composer.js     # Алгоритм автоматической сборки композиций по метафоре
│       ├── exporter.js     # Очистка и скачивание чистого векторного SVG
│       └── toast.js        # Уведомления пользователя
```

## 🚀 Запуск проекта локально

### Требования:
- Node.js 18+
- npm / pnpm / yarn

### Установка и запуск:
```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки
npm run dev

# 3. Откройте в браузере:
# http://localhost:5173
```

### Сборка для продакшена:
```bash
npm run build
npm run preview
```

## 🤖 Использование ИИ-инструментов

В процессе выполнения тестового задания применялся агентный ИИ-ассистент:
1. **Анализ исходного файла Figma:** ИИ-браузер исследовал все 4 страницы макета (`Задание`, `Библиотека компонентов`, `Примеры композиций`), извлёк точные параметры палитр, правила компоновки, требования к типам объектов (L/S, Main/Background).
2. **Проектирование архитектуры:** разработка модульной системы без внешних UI-библиотек с чистым SVG API.
3. **Генерация изометрических SVG-ассетов:** перевод компонентов из исходных иллюстраций в структурированные векторные файлы с семантическими классами (`.fill-primary`, `.fill-secondary`, `.fill-accent`).
4. **Автоматизированное E2E-тестирование:** запуск subagent в браузере с проверкой всех пользовательских сценариев (drag & drop, смена палитр, генерация по метафоре, экспорт).
